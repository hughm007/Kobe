# <What you learned, as a statement>

> Title it as the finding, not the activity. "Price-led ad copy outperformed
> outcome-led for this audience" — not "Q3 campaign review".

## What we did

The work, the client (or a note that it's generalised), the period, the spend or scale.
Enough that someone can judge how much weight to give this.

## What happened

The numbers. Include the sample size — a result without its volume can't be judged.

| Metric | Before / control | After / variant | Change |
|---|---|---|---|
| | | | |

**Source:** which platform, which export, which date range.

## What we think it means

The interpretation, stated as a claim someone could disagree with.

**Confidence:** High / Medium / Low — and why.

Be honest here. A low-confidence learning recorded honestly is useful; a low-confidence
learning presented as settled fact will mislead a future campaign.

## How far it generalises

- ☐ Specific to this client
- ☐ Likely true for this industry / audience type
- ☐ Likely true for this channel generally
- ☐ Probably a general principle

What would have to be true elsewhere for this to transfer?

## What we'd do next

The next test, or the change this suggests.
