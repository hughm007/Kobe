# A judged panel produced a cleaner spine than solo authorship — on the same task, same constraints

## What happened
Same film, same constraint set, two authoring modes:
- **Solo** (control + challenger): reached the dual gate with **14 S4 / 23 S3** (Skeptic) and
  **4.0 / 3.3 vs a floor of 8.0** (Kobe). Multiple defects were the author's own repeat classes.
- **Panel** (Rev 3): 3 rival spines from stated angles → 3 comparative judge lenses → synthesis
  grafting the losers' best elements → adversarial checker recomputing every number. Checker:
  **PASS, 0 blocking of 8 issues, round one.** Measured deltas: max cps 12.3→9.0, offer hold
  1.4s→4.2s, safe-band violations 10/13→0/14, seam blank→drawn-through.

## Honest scope
Design-time evidence only so far — the round-2 gate verdict on the rendered Rev 3 is the real test
and was pending when this was written; update this file with it. Cost: ~1M subagent tokens, $0
external spend.

## The rule this earns (forming)
When the artifact is high-stakes and the author has already produced repeat defect classes on it,
**fan out**: rivals with genuinely different briefs, comparative judges, synthesis, and an
adversarial recompute — the diversity catches the author's blind spots because the rivals don't
share them.
