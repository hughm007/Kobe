# Copy self-refutes when read on its own placement — test every string against the surface it plays on

## What happened (all one campaign, all S4/S3 at the gate)
- `Nobody comes to your site.` — meant *jobsite*, played on a **website**. Read as "nobody visits
  this page" — self-refuting in placement.
- `servicepow.com` as the endcard — shown to a viewer **standing on servicepow.com**.
- `So it doesn't look fake.` — a realism claim burned across a **cartoon**; the claim's own carrier
  refuted it.
- The loop sentence: `Get your free growth audit.` → *[blank]* → `You paid. It didn't ring.` — on
  an infinite loop, the CTA was answered forever by "paying didn't work."

None of these is wrong in a script document. All are wrong **on the surface they play on**.

## The rule this earns
Before any render: read every burned string (a) as seen on the exact page/feed it will occupy,
(b) in loop order — last string then first string — and (c) against its own picture. A string that
fails any of the three readings is wrong even if the document reads fine. Rev 3 designed its loop
sentence first and passed the checker on round one.
