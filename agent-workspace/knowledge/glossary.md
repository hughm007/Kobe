# Glossary

Shared definitions, so a number means the same thing in every document. Where a term is
defined differently by different platforms, say so — that ambiguity is a common source of
reporting disputes.

## Measurement

| Term | Definition |
|---|---|
| **Impression** | One display of an ad. Not a person; the same person generates many. |
| **Reach** | Unique people who saw it at least once. |
| **Frequency** | Impressions ÷ reach. Rising frequency with falling performance suggests creative fatigue. |
| **CTR** | Click-through rate — clicks ÷ impressions. |
| **CPC** | Cost per click. |
| **CPM** | Cost per thousand impressions. |
| **Conversion** | A defined valuable action. **Define it explicitly per client** — this is the single most misaligned term in reporting. |
| **CPA** | Cost per acquisition — spend ÷ conversions. Only meaningful once "conversion" is defined. |
| **ROAS** | Return on ad spend — revenue ÷ spend. Excludes fees and cost of goods; not profit. |
| **Attribution window** | The period after an interaction in which a conversion is credited to it. Different windows produce different numbers from identical activity. |
| **Bounce rate** | Sessions with no qualifying interaction. Definition varies by analytics platform — always name the platform. |
| **Session** | A grouped period of activity. Session definitions and timeouts differ by platform. |

## Funnel

| Term | Definition |
|---|---|
| **Awareness** | The audience doesn't yet know they have the problem. |
| **Consideration** | They're comparing ways to solve it. |
| **Decision** | They're choosing between specific options. |
| **Retention** | Already a customer; the goal is repeat and referral. |
| **MQL / SQL** | Marketing- and sales-qualified lead. **NEEDS INPUT:** does Service Pow use these, and how are they defined? |

## Web and SEO

| Term | Definition |
|---|---|
| **Title tag** | The page title shown in search results and the browser tab. Affects ranking and clicks. |
| **Meta description** | Summary shown under the title in search results. Affects clicks, not ranking. |
| **Canonical** | The URL declared as the authoritative version when duplicates exist. |
| **301 / 302** | Permanent / temporary redirect. Use 301 for moves — 302 doesn't pass authority the same way. |
| **Core Web Vitals** | Google's page experience metrics — loading, interactivity, visual stability. |
| **NAP** | Name, address, phone. Must be identical everywhere for local SEO. |
| **Structured data** | Machine-readable markup describing page content. Only mark up what's genuinely there. |
