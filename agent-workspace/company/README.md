# company/

Everything true about **Service Pow itself** — who we are, what we sell, who we sell it
to, how we sound, what it costs.

**Belongs here:** company profile, service definitions, positioning, ICP, brand voice,
visual identity, pricing, team and roles, internal capability notes.

**Does not belong here:** anything specific to a single client (→ `clients/`), process
documentation (→ `playbooks/`), or things we've learned from doing the work
(→ `knowledge/`).

## Files

| File | Purpose |
|---|---|
| [`company-profile.md`](company-profile.md) | The one-page truth about Service Pow |
| [`services.md`](services.md) | What we sell and what each engagement includes |
| [`positioning-and-icp.md`](positioning-and-icp.md) | Who we're for, and why us over the alternatives |
| [`pricing-and-packaging.md`](pricing-and-packaging.md) | Commercial structure |
| [`brand/brand-voice.md`](brand/brand-voice.md) | How Service Pow writes and speaks |
| [`brand/visual-identity.md`](brand/visual-identity.md) | How Service Pow looks |
| [`OPEN-QUESTIONS.md`](OPEN-QUESTIONS.md) | Every unanswered question in the workspace, in one list |

## Standing rule

These files are the source of truth. If a client-facing document contradicts one of
them, the file is right and the document is wrong — or the file is stale and should be
updated deliberately, with a note in the worklog. Never let the two quietly diverge.
