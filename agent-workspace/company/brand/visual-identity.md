# Service Pow Visual Identity

How Service Pow looks. Used for anything Service-Pow-branded: the site, decks, proposals,
social templates, invoices.

For client work, use the client's own brand guide — never Service Pow's.

## Logo

**NEEDS INPUT:** Primary lockup, secondary/stacked versions, icon-only mark, mono
versions. Where the master files live (see [`../../assets/README.md`](../../assets/README.md)
for the pointer convention).

**Clear space and minimum size:** NEEDS INPUT
**Misuse — never do this:** NEEDS INPUT (stretching, recolouring, adding effects, placing
on busy imagery, rebuilding the wordmark in a different typeface)

alternative here rather than letting each designer improvise one.
