# The Style Bank (distilled)

The full bank is Karl's artifact — 61 production design systems read off live sites,
filed by archetype with exact palettes, type scales, radii and elevation rules. This
file carries the decision layer; open the artifact for a specific system's values.

## The six standing constraints (verbatim in intent)

1. **A client's brand standards outrank every palette here.** Where a brand exists,
   these systems inform structure, rhythm, radii and restraint — never the colors.
2. **Nothing here produces a keyframe, end card or logo.** Logos are real client files,
   composited — never generated (LB24). A palette is not a color grade.
3. **This is an input, never a gate** — the ad-production blocking checks decide delivery.
4. **Every conversion surface is a claim surface** — case results, before/afters,
   results metrics, urgency coloring all need written substantiation (compliance rules).
5. **Accessibility outranks fidelity** — 4.5:1 body contrast wins over any source style.
6. **Verified-as-extracted ≠ verified-as-effective.** "The visual language Linear uses"
   is a fact; "the style that converts best" is an assumption — never state it as fact.

## The nine archetypes (choose from what the buyer is anxious about)

| | Archetype | Signature |
|---|---|---|
| A | Warm editorial | warm off-white, serif display, one earth accent, elevation by tone |
| B | Clean white utility | white ground, grotesk, small radii, one blue on the single primary action |
| C | Dark precision | near-black, hairline borders instead of shadows, one rationed neon |
| D | Brutalist poster | massive condensed type, 0px containers, B/W + one signal color |
| E | Playful consumer | cream ground, generous radii, illustration, borders not shadows |
| F | Institutional trust | navy/forest ground, pill CTAs, tabular restraint, one voltage accent |
| G | Cinematic | full-bleed photography carries all color; monochrome chrome |
| H | Product showroom | object isolated on seamless ground; invisible chrome |
| I | Experimental agency | one 3D/gradient hero as the sole chromatic event |

Competence anxiety → B and F. Taste anxiety → A, G and I.
