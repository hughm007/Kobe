# CHALLENGER — "Look Us Up" pack, problem/solution-first cut — VERSION 1

**What this is (Owner directive, storyboard read #2, 2026-08-26):** a **performance
challenger built ENTIRELY from the control board's already-planned captures — no new shoot
asks.** Control = the trust-first "Look Us Up" cut (`shotlist.md` + `script.md`, the gated
board). Challenger = the same footage re-ordered problem → solution → proof → work → relief
→ CALL. **The market decides between them** — neither Claude nor Service Pow picks the
winner on paper. The Owner's own framing: *"I would not tell Claude: start over… I would
tell it to create a performance challenger using the exact same production assets."*

**Two spines, on purpose.** The spine law says a hook that needs its own body is a second
concept — so this challenger is formally a SECOND SPINE, authorized by the Owner as a
deliberate positioning A/B: **trust-first (control) vs problem/solution-first (challenger)**.
Message, promise, emotion, CTA logic, claims discipline, and every capture are IDENTICAL to
the control; only the ORDER of what the viewer learns changes.

**Chain check (per variant A and B):** each "leads into" equals the next "knows before" —
PAIN→SOLVING (someone must fix this) ✓ · SOLVING→PROOF (why this company) ✓ · PROOF→WORK
(back to the fix) ✓ · WORK→RELIEF (did it work) ✓ · RELIEF→CALL (what do I do) ✓. The A/B
hook blocks end exactly at the shared body's first "knows before" (someone must fix this) ✓.
**Shuffle test:** no two beats swap unnoticed — SOLVING before PROOF is the whole
hypothesis; PROOF before WORK is cause (verified) → effect (confidence in the continued
work); RELIEF cannot precede WORK. ✓
