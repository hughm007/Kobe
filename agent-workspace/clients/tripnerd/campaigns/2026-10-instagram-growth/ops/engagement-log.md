# Daily engagement log

One row per weekday for the routine in [`engagement-daily.md`](engagement-daily.md). Fill it in during minutes 18–20. If TripNerd's person does the outbound comments (option A), add their counts when they report back.

## How to fill it in

| Column | What goes in it |
|---|---|
| **Date** | `YYYY-MM-DD` |
| **Who** | Who did it: "ServicePOW", or TripNerd's person by role or first name. Write both if it was split, e.g. "Inbox: ServicePOW · Outbound: [name]" |
| **Minutes** | Real minutes, not 20 by default |
| **Comments left** | The number of outbound comments on other accounts' posts. Replies in TripNerd's own inbox don't count here |
| **Accounts engaged** | Count per category: **EV** event accounts · **VN** venues and host hotels · **CU** golf and sports-travel culture · **LF** fans from location pages · **PT** partners. E.g. `EV 3, VN 2, LF 6` |
| **DMs answered** | The number of DMs replied to. Add "(N handed to TripNerd)" for enquiries |
| **Notable replies or follows back** | Business, event and partner accounts by handle. **Individual fans: no handles.** Write "fan, LF, [venue]" instead. Guest Story reshares go here too, e.g. "2 guest Stories reshared" |
| **Issues** | Anything that went wrong or changed: action blocks or warnings from Instagram, Business Suite test results, follow-list changes with the reason, a complaint flagged, a minute overrun |

**Privacy:** no DM text, guest names, emails or phone numbers in this file. It's a git repo. Consent records live in TripNerd's Drive (see [`guest-loop.md`](guest-loop.md)).

**Post days:** the first-hour comment replies after a post get their own row, with the post's name under "notable".
