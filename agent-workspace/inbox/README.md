# inbox/

The front desk. Things arrive here before they have a home.

**Use it for:** a document a client sent, a link worth keeping, a half-formed idea, notes
scribbled between meetings, anything you don't want to lose while you're mid-task.

## The rule

**The inbox is a staging area, not storage.** Triage it before the session ends. Every
item leaves by one of three doors:

1. **Filed** — moved to its proper home, per the routing table in
   [`../CLAUDE.md`](../CLAUDE.md) §5
2. **Actioned** — the thing it was for is done, and the item is deleted
3. **Discarded** — it wasn't worth keeping, and saying so is a decision, not a failure

An inbox that accumulates stops being triaged and becomes a place where things go to be
forgotten. If something has sat here for more than a week, that's a signal: file it or
bin it.

## Naming

`YYYY-MM-DD-what-it-is.md` — so age is visible at a glance.
