# Kobe

This repository hosts the **Service Pow agent workspace** — the working office for
Service Pow's AI agent.

The office (rules, playbooks, knowledge, other clients) lives in [`agent-workspace/`](agent-workspace/).
TripNerd's files live in [`ServicePOW/Clients/TripNerd/`](ServicePOW/Clients/TripNerd/README.md), folders 01–08. Start with
[`agent-workspace/CLAUDE.md`](agent-workspace/CLAUDE.md).

> Working with Claude Code? Run it from the **repo root**. Root `CLAUDE.md` loads the Service Pow
> LAW and the workspace constitution (`agent-workspace/CLAUDE.md`), and the project skills live in
> root `.claude/skills/`. Launching inside `agent-workspace/` would miss the skills.
