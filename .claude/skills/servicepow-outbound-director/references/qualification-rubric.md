# Local-SMB qualification rubric
Single home of Service Pow's own prospect-qualification method. Derived from `marketingskills`
`local-prospecting.md` (MIT, Corey Haines), re-expressed — it formalizes the axis our
brand+web offering sells against.

## Website status — the core qualification axis (four states)
| Status | Definition | Outcome for Service Pow |
|---|---|---|
| **No site found** | No credible standalone website after cross-checked search | **Hot** — web/brand/marketing prospect |
| **Social only** | Facebook/Instagram/Linktree/booking portal only | **Hot** |
| **Weak site** | Site exists but outdated, thin, broken, non-mobile, or missing a conversion path | **Warm** — refresh/rebuild prospect |
| **Has site** | Credible modern site | **Low**, unless other signals apply (weak local SEO, poor conversion design, bad reviews handling) |

## Signals
- **Operational (active business):** GBP updated · recent reviews · hours posted · recent
  owner photos · owner responding to reviews.
- **Proximity:** distance/travel time to the served metro; density clusters = neighborhood
  targeting opportunities.
- **Decay (disqualify):** closed banner · listing reported closed · last activity >12 months.

## Discovery workflow (browser-first, ToS-respecting)
1. Search maps for "category near [location]"; walk visible results — **no bulk extraction of
   Maps/Yelp or any ToS-protected platform; discovery stays manual.**
2. Cross-verify via the business's own site, industry directories, chamber listings, state
   registries, and "[name] [city]" search.
3. Classify website status; record **confidence**: High (2+ sources) / Medium (1 source +
   consistent evidence) / Low (incomplete) — Low-confidence rows are never contacted until
   upgraded.
4. Programmatic checks are allowed only against an individual business's OWN url (is it live,
   mobile-friendly, conversion-equipped) — never against aggregator platforms.

Every qualification row is evidence-labeled (see the evidence ladder in
`../../servicepow-client-intelligence/references/evidence-ladder.md`); a "weak site" verdict
must cite what was observed, dated.
