# QA3 — advertising self-check (pre-critic)
Run by the producer BEFORE handing to the readiness authority. This is a self-check that
catches rework early; **it issues no verdict** — the client-ready score is owned solely by
`../../servicepow-creative-critic/` (ServicePow-6, BC-22), and the adversarial attack solely
by the isolated Skeptic pass (BC-23).

Checklist (fix before submission, then submit):
- HOOK: do the first 2.5 seconds earn attention with an IDEA, not a camera move?
- CLARITY: does each beat state one thing a viewer instantly understands, sound-off?
- **Designed slots filled:** every label plate, caption window, and text slot the shot
  design declared is actually populated (paid for on 2026-09-03 — three reviewers
  unanimously killed a cut for empty label plates).
- OFFER/CTA: is the action explicit, and every required mark (licence, phone) on screen for
  its dwell time?
- BRAND: real marks only, palette held, lane declared and consistent.
- CLAIMS: every line inside the client's claims bounds; nothing softened, nothing invented.
- PACING: no beat that exists for atmosphere alone; removal test applied.
- VO fit: lines budgeted at the voice's MEASURED read rate (~2.4 words/sec for the current
  preset) at script time — trim silence before judging any take (2026-09-03 learning).
