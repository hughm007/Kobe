# Extraction schema — one record per competitor

Every field carries a label: CONFIRMED OBSERVATION / EVIDENCE / INFERENCE / UNKNOWN.
Source + date on every observation. UNKNOWN states what would resolve it.

| Field | What to capture |
|---|---|
| competitor | Legal/trading name, locations, apparent size |
| offer | What is actually sold, at what stated price/terms; lead magnet if any |
| target audience | Who the creative addresses (spoken to, shown, targeted placements) |
| hooks | Opening 1–3s device per observed ad, verbatim where possible |
| angles | The argument each ad makes (speed, price, trust, fear, identity…) |
| creative mechanism | What does the persuasive work — demonstration, social proof, urgency, authority, humor, before/after |
| visual language | Production style, palette, typography, real-vs-stock-vs-synthetic feel |
| CTA | The action asked for and its friction |
| funnel structure | ad → destination → capture → follow-up, as far as observable |
| landing-page behavior | Opened, on mobile too: ad parity, load, capture form, phone prominence, brokenness |
| proof mechanisms | Reviews (count/recency/platform), guarantees, credentials, case material — and whether substantiation is visible |
| positioning | The sentence they are implicitly claiming about themselves |
| strengths | What they demonstrably do well |
| weaknesses | Observed/evidenced gaps only — never wishful |

Cross-competitor section: conventions (what everyone does) · vacancies (what no one does) ·
the loudest spender's mechanism · the best creative's mechanism.
